# Emergency Sound Files

This directory contains sound files used for emergency alerts in the application.

## Required Files:

-   `emergency-alert.mp3` - Sound played when a new emergency (pending) report is detected

Please replace the placeholder file with appropriate emergency sounds. The sound files should be:

-   Short duration (2-5 seconds)
-   Clear and attention-grabbing
-   Compatible with web browsers (MP3 format recommended)
-   Properly licensed for use in your application

You can find free sound effects from sources like:

-   [Freesound.org](https://freesound.org)
-   [Mixkit](https://mixkit.co/free-sound-effects/alert/)
-   [Zapsplat](https://www.zapsplat.com/sound-effect-categories/alerts-and-prompts/)
